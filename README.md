### Bounce Back

## Controls

| Action | Keys |
| --- | --- |
| Move paddle | Mouse, A/D, or left/right arrows |
| Launch ball | Space or left click |
| Pause | Esc |
| Mute | M |

## Power-ups
| Letter | Effect |
| --- | --- |
| W | Wide paddle for 12 seconds |
| M | Multi-ball, up to 9 balls |
| S | Slow motion for 8 seconds |
| B | Shield that saves the ball once |
| + | Extra life (max 5) |
